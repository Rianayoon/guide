표 ② 사찰의 불전 최빈출

불전모신 대상 · 내용
개념부처나 보살 등 불교 신앙의 대상이 되는 불상을 모신 전각
대웅전석가모니불을 모신 전각 · 사찰의 중심 → 수덕사 대웅전(고려), 봉정사 대웅전(조선)
극락전· 서방 극락정토의 주재자인 아미타불을 모신 불전 → 「무량수전」·「아미타전」·「보광명전」
· 고려 : 안동 봉정사 극락전, 영주 부석사 무량수전
대적광전비로자나불(지혜의 빛)을 모신 불전 → 「비로전」·「화엄전」·「대광명전」
약사전(보광전)약사여래불(치료·수명 연장)을 모신 불전 → 좌우에 일광·월광 보살 배치 · 「유리광전」
팔상전부처의 일생을 그린 팔상탱화를 모신 불전 → 「영산전」 · 법주사 팔상전
미륵전(용화전)용화세계에서 중생을 교화하는 미륵불(미래불)을 모신 불전 → 김제 금산사 미륵전
지장전지장보살(지옥의 중생 구제)·염라대왕 등 10왕을 모신 불전 → 「명부전」·「시왕전」
관음전(원통전)자비를 상징하는 관세음보살을 모신 불전 → 현세의 중생을 환란과 고통으로부터 구제
응진전(나한전)부처님의 제자인 16나한(아라한)을 모신 불전
문수전문수보살 — 지혜 제일
적멸보궁· 석가모니불의 진신사리를 모신 불전 → 불상 없음 · 계단과 사리탑 설치
· 5대 적멸보궁 : 양산 통도사, 평창 오대산 중대 상원사, 설악산 봉정암, 영월 법흥사, 정선 정암사

표 ③ 사찰의 기타 건물 · 범음구

구분내용
삼성각칠성각(북두칠성) · 산신각(산신) · 독성각(나반존자) → 사찰 뒤쪽 위치 · 민간 신앙 반영
삼묵당말을 하지 않는 장소 → 식당, 욕실, 화장실(해우소·동사)
장경각불경, 불경을 새긴 목판을 보관한 전각 → 해인사 장경판전
범종각사찰의 4물 — 범종, 법고, 목어, 운판 등 보관
조사당(국사전)종파의 조사, 사찰의 창건주 등을 기리기 위해 건립 → 부석사 조사당, 송광사 국사전
범음구· 법고(홍고) : 의식용 범음구 → 불법을 전하는 소리를 상징
· 목어 : 수중의 생명을 제도하기 위한 범음구 → 불공 또는 사람을 모으는 수단으로 사용
· 운판 : 하늘을 나는 생명을 제도하기 위한 범음구 → 식사 시간을 알릴 때 사용
· 반자(금고) : 금속으로 만든 쇠북 → 절에서 대중을 불러 모으거나 급한 일을 알릴 때 사용
· 법라 : 나팔 고동 끝부분에 작은 구멍을 뚫고 금속제 피리를 붙여서 만든 악기 → 법회 때 사용

표 ④ 한국의 주요 사찰 — 삼보사찰 최빈출

사찰내용
삼보사찰삼보(三寶) → 진리를 깨우친 부처님(佛) · 부처님이 설하신 법(法) · 부처님의 가르침에 따라 수행하는 스님(僧)
통도사· 신라 선덕여왕 때 자장 창건 → 계율종 중심 사찰, 경남 양산에 위치
· 불보사찰(부처님의 진신사리 봉안), 대웅전(불상 없음), 5대 적멸보궁, 금강계단 등
해인사신라 순응·이정이 창건(802년) · 가야산 국립공원에 위치 · 법보사찰(팔만대장경 보관) → 장경판전(세계 문화유산)
송광사신라 말 혜린이 창건 → 전남 순천 조계산 도립공원에 위치 · 승보사찰(보조국사 지눌 등 16명 국사 배출) · 조계종의 발상지
화엄사신라 경덕왕 때 창건(754년) → 지리산 국립공원에 위치 · 각황전(석가모니불, 사찰의 중심), 대웅전(비로자나불), 4사자 3층 석탑

표 ⑤ 한국의 주요 사찰 — 그 밖의 사찰 최빈출

사찰내용
부석사신라 문무왕 때 의상 창건 → 「부석(浮石)」 바위, 화엄종의 본찰, 선묘각(선묘 낭자의 초상화), 무량수전(주심포), 소조 여래 좌상
낙산사신라 문무왕 때 의상 창건 → 강원도 양양에 위치 · 2005년 화재로 다수의 문화재 소실 · 해수관음 사찰, 홍련암·의상대, 관동팔경
범어사신라 문무왕 때 의상 창건 → 부산 금정산에 위치 · 화엄종 사찰
법주사신라 진흥왕 때 의신 창건 → 충북 보은 속리산 국립공원에 위치 · 팔상전(5층 목탑), 대웅전, 쌍사자 석등
백담사신라 진덕여왕 때 자장이 한계사로 창건 → 설악산 국립공원에 위치 · 신흥사의 말사 · 조선 정조 때 「백담사」로 개칭 → 봉정암(5대 적멸보궁)
월정사신라 선덕여왕 때 자장 창건(643년) → 강원도 평창 오대산 국립공원에 위치 · 월정사 8각 9층 석탑

표 ⑥ 불탑 — 구조와 시대별 불탑 최빈출

구분항목내용
개념 · 종류—석가모니의 진신사리를 봉안하기 위한 축조물
· 재료 → 목탑 · 석탑 · 전탑 · 모전석탑    · 형태 → 복발탑 · 중층탑 · 이형탑
석탑의 구조기단부하대석·상대석으로 구성 → 지대석, 탱주, 우주, 면석, 갑석
탑신부탑신석(돌), 옥개석(지붕돌), 옥개(층급) 받침 → 탑신석과 옥개석에 의해 탑의 층수 결정
상부노반 → 복발 → 앙화 → 보륜 → 보개 → 수연 → 용차 → 보주 → 찰주
시대별 불탑고구려현존하는 불탑 없음 → 주로 목탑이 축조된 것으로 보임
백제부여 정림사지 5층 석탑 — 「평제탑」 / 익산 미륵사지 석탑 → 무왕 때 축조, 목탑 양식 석탑, 현존 최고(最古)의 석탑
신라· 황룡사 9층 목탑 : 선덕여왕 때 자장의 건의로 백제의 아비지가 건립 → 몽골 침략으로 소실
· 분황사 모전 석탑 : 선덕여왕 때 축조, 3층만 현존, 탑신에 인왕상 배치
통일 신라· 불국사 3층 석탑 : 아사달·아사녀의 전설 · 석가탑·무영탑 · 무구정광대다라니경 발견
· 화엄사 4사자 3층 석탑, 다보탑(이형탑) / 안동 신세동 7층 전탑 — 최고·최대 전탑
고려월정사 8각 9층 석탑(송의 영향 — 고려 초기), 경천사지 10층 석탑(원의 영향, 대리석으로 축조)
시대별 불탑조선· 원각사지 10층 석탑(국보 제2호) — 세조 때 경천사지 10층 석탑 모방 → 대리석으로 축조 · 3층 기단으로 구성, 각 층 옆면에는 여러 가지 장식 조각
· 법주사 팔상전 → 우리나라 유일의 5층 목탑

표 ⑦ 불상 최빈출

구분항목내용
주요 명칭수인부처의 손·손가락의 모습 → 불상의 종류를 판단하는 근거 / 석가불 — 항마촉지인·시무외인·선정인·전법륜인 등
광배부처님의 몸에서 발산하는 진리와 지혜의 빛(光明) → 두광·신광으로 구성
우견편단법의(가사)의 오른쪽 소매를 벗어서 어깨를 드러낸 것
기타육계 → 부처님의 정수리에 솟은 상투 모양의 머리 / 나발 → 부처님의 머리카락
시대별 불상삼국시대· 금동미륵보살반가사유상 : 삼국 공통 제작 → 국보 제78호·제83호
· 고구려 — 연가 7년명 금동 여래 입상(현존하는 가장 오래된 불상) / 백제 — 서산 용현리 마애여래 삼존상(백제의 미소)

· 통일 신라 3대 금동불상 : 불국사 금동 비로자나불좌상, 불국사 금동 아미타여래좌상, 경주 백률사 금동 약사여래입상
고려부석사 소조 아미타여래좌상, 논산 관촉사 석조미륵보살입상(최대 석불 입상)

표 ⑧ 승탑 · 석등 · 탑비 · 범종 · 당간지주 최빈출

구분항목내용
승탑(부도)개념신라 말 선종 불교의 영향 · 승려의 사리를 모신 탑 → 지방 호족의 정치적 역량 반영
신라 말전 흥법사지 염거화상탑 → 현존하는 가장 오래된 승탑(844년), 쌍봉사 철감선사 승탑
고려팔각원당형 — 여주 고달사지 승탑, 구례 연곡사 북 승탑 / 특이형 — 법천사 지광국사 현묘탑
석등개념부처의 광명과 지혜 상징 → 「광명등」, 사찰의 대웅전 또는 석탑 앞에 배치
내용백제 — 익산 미륵사지 석등(현존하는 가장 오래된 석등) / 통일 신라 — 법주사 쌍사자 석등, 화엄사 각황전 석등
탑비개념승려의 생애를 기록한 비 → 선종의 유행으로 신라 말부터 등장
내용신라 말 — 보령 성주사지 낭혜화상 탑비, 하동 쌍계사 진감선사 대공탑비 / 고려 — 천안 봉선 홍경사 갈기비
범종개념중생을 제도하는 불구 → 절에서 사람을 모이게 하거나 시각을 알리기 위하여 치는 종
통일 신라상원사 동종 — 현존 최고(最古) 범종 / 성덕대왕신종 — 에밀레종·봉덕사종, 비천상 무늬, 현존 최대(最大) 범종
고려수원 용주사 종, 탑산사 종
당간지주개념당(불화를 그린 깃발)을 걸었던 장대, 즉 당간을 지탱하기 위하여 당간의 좌우에 세우는 기둥 → 사찰 입구에 세움
내용재료 — 돌로 만드는 것이 보통 → 철제·금동제·목재 / 현존하는 당간지주는 대부분 통일 신라 이후 축조
