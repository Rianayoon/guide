표 ① 전통 무용 최빈출

구분무용내용
궁중무용
(정재무)		의미궁중에서 연회·나례·사신 접대 등에서 연행되던 춤 · 악가무일체(영산회상·여민락·보허자 등 연례악 사용)
처용무· 신라 헌강왕 때의 처용설화에서 비롯된 가면무 → 가장 오래된 조선 시대 궁중무, 세계 인류무형문화유산
· 궁중 중요 연례·나례(섣달 그믐날) → 사람 형상의 탈을 사용하는 유일한 궁중무, 5방 처용무(음양오행설)
춘앵전조선 순조 때 효명세자가 창작한 궁중 무용의 유일한 독무 → 버드나무 가지에서 지저귀는 꾀꼬리의 모습을 보고 창작
일무종묘·사직·문묘대제 등 제향 의식에서 여럿이 줄을 맞추어 춤을 추는 집단 의식무 → 팔일무(64명)
작법무개념불교 의식 무용
종류· 나비춤 : 나비 의상을 입고 고깔을 쓰고 모란꽃을 양손에 들고 추는 춤 → 착복무
· 바라춤 : 양손에 바라를 들고 빠른 동작으로 전진·후퇴 또는 회전을 하며 활달하게 추는 춤
· 법고춤 : 법고를 두드리며 범패를 반주음악으로 해서 장삼을 걸치고 양손에 북채를 들고 추는 춤
민속무강강술래추석에 전남 지역에서 행해진 여인의 민속놀이 → 임진왜란(이순신), 세계 인류 무형 문화유산
승무흰 장삼에 붉은 가사를 어깨에 매고 흰 고깔을 쓰고 추는 민속춤 → 불교적 색채의 독무
살풀이춤남도 지방 무속무 계통의 춤 → 살(액)을 푼다(제거한다)는 뜻을 가진 민속무용
농악무농악에 맞추어 추는 농민 무용 → 상모놀이, 너름새(어깨춤), 설 장고춤 등
한량무진주 지방의 전통 무언무용극 → 한량과 승려가 한 여인을 유혹하는 내용을 표현 → 조선 후기 양반과 파계승 풍자
허튼춤형식에 얽매이지 않고 자유롭게 추는 춤 → 굿판·농악판·탈판·잔치판의 현장(어깨춤)

표 ③ 민속놀이 최빈출

놀이내용
차전놀이· 경북 안동 → 정월 대보름날 낮에 행하던 남성 민속놀이 → 「동채싸움」이라고도 함 · 농경민의 풍년 기원
· 동채꾼은 대장·머리꾼·동채꾼·놀이꾼 등으로 구성(25~40세 남자 500여 명 참여) → 견훤(후백제)과 왕건(고려)의 고창(안동) 전투와 관련
놋다리밟기· 경북 안동 → 정월 대보름 밤에 행하는 여성 집단 놀이 → 「놋다리」는 「시냇물 위에 놓은 다리」란 뜻 → 「기와 밟기」
· 기원 : 공민왕이 홍건적 침략으로 안동 지방으로 파천했던 당시에 노국공주가 시내를 쉽게 건널 수 있도록 사람 다리를 놓았던 데서 유래
고싸움놀이광주 남구 대촌동 칠석마을에서 정월 대보름에 행하는 남성 집단 민속놀이 → 짚으로 만든 「고」를 기구로 하여 승부를 겨루는 놀이
줄다리기(줄쌈)정월 대보름 → 풍농 기원, 공동체의 화합과 단결 목적으로 실시 → 세계 인류무형문화유산 · 창녕 영산 줄다리기, 당진 기지시 줄다리기
달집 태우기정월 대보름 밤에 생솔가지 등을 쌓아 「달집」을 짓고 불을 놓아 제액초복 기원하는 풍속 → 풍농과 긴밀한 관련
지신밟기(집돌이)정초에서 정월 대보름 사이에 마을굿을 통해 공동신에 대한 의례를 치르고 집터 곳곳의 지신을 밟아 한 해의 안녕과 복덕을 기원
백중놀이백중날(음력 7월 15일) → 연간 농작물 재배의 핵심적인 활동을 모두 마치고 머슴들이 하루를 먹고 노는 세시풍속
차첨지 놀이전라남도 진도군에서 행해지는 강강술래의 여흥놀이로 행해진 집단적 가무 놀이 → 「외따 먹기 놀이」
방천놀이함경북도 종성에서 행하던 부녀자들이 냇물이 넘치는 것을 막기 위해 쌓은 둑이나 나무숲에서 행하던 놀이
봉죽놀이조기잡이가 성행하였던 서해안 마을에서 정월 열나흗날 고기잡이 나갔던 배가 포구로 들어오면서 춤과 노래를 부르며 풍어를 기원

표 ④ 전통 가면극(탈춤) 최빈출

가면극내용
개념가면을 쓰고 산대(무대)에서 음악에 맞추어 춤과 대사로 연극 → 조선 후기 유행(현실 사회 비판)
양주 별산대놀이국가 무형유산 제2호 → 「산대놀이」는 중부 지방(서울·경기)에서 성행한 탈춤 → 파계승·몰락 양반·무당·하인 등 등장
오광대놀이
(들놀음·야류)		· 경상남도 일대에 분포 · 음양오행설에 의거한 5마당의 탈춤극 → 정월 대보름에 공연
· 내용 : 양반 계급에 대한 반감, 파계승에 대한 풍자, 남녀 애정 관계에서 오는 가정의 비극 등
· 통영 오광대놀이 : 문둥탈·풍자탈·영노탈·농창탈·포수탈의 5마당 → 문둥이, 말뚝이 등 31명 인물 등장 + 사자춤 병행
· 고성 오광대놀이 : 문둥이·오광대춤·중춤·비비춤·제밀주의 5마당으로 구성
· 동래야류 : 줄다리기와 함께 연행 → 문둥이·양반·영노·할미 마당의 4마당으로 구성
· 수영야류 : 산신제와 함께 연행 → 양반 마당, 할미·영감 마당, 영노 마당, 사자춤의 4마당으로 구성 → 문둥이 마당 ×
북청사자놀음· 함경남도 북청군에서 정월 대보름을 전후하여 연희된 사자놀이 → 벽사진경
· 특징 : 사자·양반·꺽쇠·꼽추·사령은 가면 사용 ○ / 무동·사당·중·한방의 거사는 가면 사용 ×
봉산 탈춤황해도 봉산 지방의 가면극 → 단오·하지날 밤에 공연, 7마당, 벽사진경, 26개 탈(말뚝이·취발이·먹중·양반·무당·영감 등)
송파산대놀이조선 시대에 송파장에서 공연 · 서울에서 유일하게 존재하는 가면극 → 12마당, 32개 탈
하회별신굿탈놀이· 경북 안동의 하회동·병산동에서 공연된 탈춤 → 현존하는 가장 오래된 가면극, 하회탈 11개 + 병산탈 2개 → 총 13개
· 내용 : 성황신(마을 수호신)에게 제사를 올리고 풍년을 기원했던 풍습에서 유래
세계 인류 무형

남사당놀이· 개념 : 남사당(남자 유랑예인)에 의해 행하던 민속 공연 → 국가 무형유산 제3호, 세계 인류 무형 문화유산
· 특징 : 서민층 대상으로 모심는 계절 ~ 추수가 끝나는 늦가을까지 공연 → 벽사진경, 계급사회의 부조리함과 양반 비판

표 ⑤ 도자기 — 청자 · 분청사기 · 백자 최빈출

구분항목내용
청자특징고려 시대 유행 → 귀족의 사치품으로 주로 제작
도요지전남 강진, 전북 부안·진안, 강화도
내용· 비색(순)청자 : 상감법이나 다른 안료를 사용하지 않은 순수 비색 청자
· 상감청자 : 상감법을 이용하여 무늬를 넣은 청자 · 12세기 중엽~13세기 중엽 유행
  상감법 : 나전칠기와 은입사 공예에서 응용 → 그릇 표면을 파낸 자리에 백토·흑토를 메워 무늬를 내는 방법
· 철화청자 : 검은색 안료를 사용하여 붓으로 그릇 표면에 무늬를 그린 후 유약을 입혀 구워낸 황갈색 자기
· 진사청자 : 붉은색 안료로 그릇 표면에 무늬를 그린 다음에 청자 유약을 입혀서 구워낸 자기
· 화금청자 : 상감된 무늬의 일부에 금을 칠하여 구워낸 자기
분청사기시기고려 원 간섭기~조선 초 15세기까지 유행 → 막사발·찻잔·대접 등의 용도로 생산, 모란꽃·국화·물고기·나비 등을 소재로 사용
특징청자에 백색의 분과 안료로써 무늬를 만들어 장식한 회청색 자기 → 「분장 회청사기」의 준말
분장 기법· 인화 기법 : 일정한 무늬를 도장과 같이 만들어 그릇 표면에 찍은 뒤 백토 분장하는 기법
· 상감 기법 : 조각칼로 그릇에 문양을 새긴 다음 자토와 백토로 문양을 메우는 기법
