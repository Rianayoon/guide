표 ④ 전통 건축의 구성 요소 — 지붕 최빈출

구분내용
지붕의 기능비·눈·햇빛 등으로부터 건물 보호, 생활의 편리함, 권위의 상징, 의장적 기능
지붕의 구조물· 서까래 : 지붕의 뼈대를 이루는 나무
· 도리 : 서까래 아래에 위치하여 지붕을 받치는 데 쓰이는 부재
· 처마 : 서까래가 지붕 밖으로 빠져나간 부분, 지붕이 도리 밖으로 내민 부분 → 비·눈으로부터 집의 외벽 보호, 일조량 조절
· 추녀 : 처마와 처마가 일정한 각도로 만나는 부분에 경계를 이루듯이 걸치는 건축 부재
· 보 : 기둥 위에서 지붕의 무게를 전달해 주는 건축 부재(대들보)
· 지붕마루 : 용마루 · 내림마루 · 추녀(귀)마루
맞배지붕· 내용 : 책을 덮어놓은 모양. 건물 모서리에 추녀(귀)마루가 없고 용마루까지 측면 벽이 삼각형으로 된 지붕 → 용마루·내림마루 ○ / 추녀마루 ×
· 특징 : 주심포 계통 건물에서 주로 사용 → 수덕사 대웅전, 무위사 극락전, 부석사 조사당
우진각 지붕· 내용 : 건물 사면에 지붕면이 있고 추녀마루가 용마루에서 만나게 되는 지붕 → 용마루·추녀마루 ○ / 내림마루 ×
· 특징 : 초가지붕과 궁궐의 정문에서 주로 사용 → 경복궁 광화문, 창덕궁 돈화문
팔작(합각)지붕· 내용 : 우진각 지붕 위에 맞배지붕을 올려놓은 형태 → 가장 화려하고 장식적인 지붕
· 특징 : 용마루·내림마루·추녀마루 모두 ○ · 다포 계통 건물, 궁궐의 정전·사찰의 법당
· 건축물 : 경복궁 근정전, 창덕궁 인정전, 부석사 무량수전, 낙산사 홍련암 대웅전 등
모임(삿갓)지붕· 내용 : 하나의 꼭짓점에서 지붕골이 모이는 지붕 → 추녀마루 ○ / 용마루·내림마루 ×
· 특징 : 정자·탑 등에 사용 → 경복궁 향원정(육모 지붕)

· 취두 : 고려 후기 이후 사용 → 치미 대신에 용마루 양쪽에 얹는 용머리 모양의 장식

표 ⑥ 기둥 · 초석 · 기단 · 월대

구분항목내용
기둥개념지붕의 하중을 초석(주춧돌)에 전달하는 구조물
· 궁궐·사찰·관아 등에 사용 → 배흘림 기둥, 민흘림 기둥, 원통형 기둥
각주· 방주(4각) : 궁궐의 정전·부속 전각·일반 주택 → 경복궁 경회루
· 육각주 : 정자에 주로 사용 → 경복궁 향원정 / 팔각주 : 사찰의 추녀를 받치는 활주에 사용
도량주나무의 껍질만 벗겨내고 원래 모양 그대로 기둥을 세운 양식
활주지붕 추녀 밑을 받치는 보조 기둥 → 송광사 대웅전
초석(주춧돌)개념기둥을 통해 전달된 상부의 하중을 지반으로 전달. 지면의 습기로부터 기둥뿌리를 보호해주는 부재
종류· 막돌(자연석) 초석 : 자연 상태의 돌을 적당한 크기로 하여 사용하는 것
· 다듬돌 초석 : 가공 형태에 따라 원형·방형·팔각형 초석으로 구분
그랭이질주춧돌과 기둥 사이를 맞물리게 하고, 기둥들의 높이를 일정하게 만드는 공법
기단개념 · 목적건축물의 하중을 지탱하는 최하부 구조물 → 건물 터보다 한층 높게 쌓은 단
· 목적 : 건물의 하중을 받아 지반에 골고루 전달, 빗물·지하수로부터 건물 보호, 건물의 장중함과 위엄을 표현
종류토축 기단, 전축 기단(벽돌), 석축 기단, 와적 기단(기와) / 적석식 기단(돌을 쌓는 방식), 가구식 기단(가공한 돌로 축조)
월대—조선 시대 궁궐의 정전과 같은 중요한 건물 앞에 놓이는 넓은 대 → 궁궐에서 하례·가례·제례 등 각종 행사 장소로 이용, 주요 건물의 권위 표현 기능 → 경복궁 근정전(2층), 종묘의 정전·영녕전

표 ⑦ 천장 · 단청 · 문 · 대문

구분항목내용

단청
(삼국시대)		재료암채 → 천연 안료

· 단청색 : 음양오행설 근거 → 청색·적색·황색·백색·흑색의 5방색 기본
목적· 건축물 수명 연장(방풍·방부·방습 효과)

· 재질의 조악성 은폐 : 목재의 표면에 나타난 옹이·흠집 등을 감추기 위해, 기념비 건축물의 전시
종류· 금단청 : 건축물 부재 중간에 비단처럼 다양하고 화려한 색과 문양으로 표현 (사찰)
· 모로 단청 : 부재의 두 끝 부분을 화려한 색과 문양으로 표현 (궁궐·관청)
· 가칠 단청 : 문양을 그리지 않고 동일한 색으로 전체 바탕을 마무리 (종묘)
· 긋기 단청 : 가칠한 위에 흑백의 선을 그어서 단순·장엄함을 표현 (사당 부속 건물)
· 얼금 단청 : 금단청과 모로 단청의 절충형 → 사찰
문(門)—· 장지문 : 방과 방 사이, 방과 마루 사이에 간을 막아 끼우는 문
· 분합문 : 대청과 방 사이 또는 대청 전면에 설치하여 접어 열 수 있게 만든 큰 문
대문—· 솟을대문 : 초헌(가마)을 타고 출입할 수 있도록 좌우 행랑보다 지붕을 높게 하여 설치한 대문 → 양반 사대부 권위의 상징
· 평대문 : 기둥의 높이를 주변의 담장이나 행랑의 높이와 같게 한 대문
· 사주문 : 담장에 대문을 설치할 때 주로 이용되던 것으로 기둥을 네 개 세워 단 간의 대문
· 삼문 : 궁궐·성곽 정문과 서원·향교·사당 정문에 사용되는 대문 → 평삼문, 솟을삼문 등
