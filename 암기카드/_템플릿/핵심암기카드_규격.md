# 핵심암기카드 규격 (확정본)

사용자가 **"핵심암기카드 만들거야"** 라고 하면 이 문서 그대로 만든다.
스타일과 순서는 이미 확정된 것이므로 **새로 디자인하지 않고, 어떻게 만들까요 하고 묻지 않는다.**

---

## ★ 절대 넣지 않는 것 — 이것부터 읽는다

> **모아놓은 박스 금지, 구구절절 설명 금지!**

1. **틀리기 쉬운 것을 모아놓은 박스를 만들지 않는다.** 사용자는 그걸 보면 더 헷갈린다. 부품 자체를 삭제했으니 되살리지 않는다. 사실은 해당 슬롯에 한 번만 적는다.
2. **내 생각을 넣지 않는다.** 쉬운 풀이, 비유, 요약 한 줄, 외우는 요령, "이게 갈림길이다" 같은 코멘트 전부 금지. 사용자가 메모에 쓴 문장만 쓴다.
3. **메모에 없는 사실을 추가하지 않는다.** 아는 내용이어도 넣지 않는다(장소·인물·연도·별점 전부). 빠진 것 같으면 카드를 만든 뒤 따로 물어본다.
4. 메모에 오타나 틀린 내용이 있어 보이면 **고치지 말고 사용자에게 물어본다.** 내 판단으로 바로잡지 않는다.

이 세 가지는 스타일 취향이 아니라 **반복해서 어겨온 실수**다. 카드를 보내기 전에 이 목록을 다시 확인한다.

---

## 0. 이 카드가 뭔지 — 이걸 모르면 다 틀린다

사용자는 **동영상 강의를 보면서 필기하는 대신 이 카드에 적는다.** 그래서 넘어오는 메모는

- 강사가 말한 순서대로라 **두서가 없고**
- 중간에 생각난 걸 뒤에 덧붙이고
- 같은 항목이 여기저기 흩어져 있다.

**받은 순서대로 만들면 안 된다.** 아래 §4의 고정 순서로 재배열하는 것이 이 작업의 핵심이다.
사용자는 시험 직전에 이 카드만 훑는다. 그때 **카드마다 같은 자리에 같은 종류가 있어야** 눈이 빨리 붙는다.

- A4 **가로 1장**에 한 주제를 압축. 아이패드로 보고 종이로 뽑는다.
- 단원 학습페이지(스토리텔링 긴 글)와 **완전히 다르다.** 이야기도 문제도 없다.
- 문장이 아니라 **키워드**로 쓴다.
- 한 파일에 `.card` 여러 장 가능(예: 부여·고구려 = 카드 2장). 인쇄하면 카드마다 새 페이지.

---

## 1. 만드는 법

1. **`핵심암기카드/{과목}/`의 완성본이 디자인의 기준이다.** 구조가 가장 가까운 카드 하나를 골라 **그 뼈대를 그대로 복사하고 내용만 갈아끼운다.** 배치를 내 판단으로 바꾸지 않는다.
2. `핵심암기카드/_템플릿/핵심암기카드_템플릿.html`을 복사한다.
3. `<style>`과 맨 아래 `<script>`는 **한 글자도 건드리지 않는다.**
4. `<div class="card">` 안의 내용만 §4 순서대로 채운다.
5. **보내기 전에 렌더링해서 눈으로 본다.** 코드만 보고 보내지 않는다.
   - 같은 단어·같은 라벨이 두 번 이상 나오면 합친다 (정의 상자와 비교표에 같은 항목이 반복되면 **한 표로 합친다**)
   - 표는 `table-layout:fixed`로 열 너비를 고르게, 색은 위 상자와 같은 계열로
   - A4 가로 1장을 넘으면 카드를 나눈다
6. 카드와 함께 **"메모에 없던 것: (목록 또는 없음)"** 한 줄을 적는다.

CSS를 새로 쓰거나, 색을 추가하거나, 폰트 크기를 조정하지 않는다.

## 2. 파일 위치·이름

```
핵심암기카드/국사/국사3단원_삼국왕계보.html
핵심암기카드/자원/자원_공포양식.html
핵심암기카드/법규/법규2단원_관광기본법.html
```

- `{과목}{단원}_{주제}.html`. 단원이 안 걸치면 `{과목}_{주제}.html`.
- 기존 파일을 고칠 땐 `_백업_수정전/`에 `.bak`으로 먼저 복사.
- **Vercel 배포 안 함. PDF 자동 출력 안 함.** 로컬 iCloud 파일로만 쓴다.

## 3. 부품 8개 — 이게 전부다 (없는 부품을 만들지 않는다)

### ① 제목줄 `.hd`
```html
<div class="hd">
  <h1>고 조 선</h1>
  <span class="tag">BC 2333 건국</span>
  <span class="tag">청동기 시대</span>
  <div class="sub"><em>BC 108 왕검성 함락 → 멸망</em></div>
</div>
```
- `h1`은 **글자 사이를 한 칸씩 띄운다** (`고 조 선`, `주 심 포 양 식`). 이 카드의 얼굴이다.
- `.tag` = 검은 알약 배지. 시대·개수·별점(`★★★ 최빈출`) 같은 짧은 것. 2~3개.
- `.sub em` = 붉은 한 줄. 그 주제 **최빈출 한 방**만. 없으면 생략.

### ② 줄 `.row`
`.r3`(3열) · `.r2`(2열) · `.r1`(1열). 960px 아래에선 자동 1열.

### ③ 상자 `.box` — 색은 순서대로 돌려쓴다
| 클래스 | 색 | |
|---|---|---|
| `.box` | 금색 | 1번째 |
| `.box.b2` | 남색 | 2번째 |
| `.box.b3` | 주황 | 3번째 |
| `.box.b4` | 초록 | 4번째 |
| `.box.b5` | 갈색 | 5번째 |
| `.box.key` | **빨강** | **전성기·최빈출 전용.** 카드당 1~2개. |

색 자체에 뜻은 없다. **한 줄 안에서 색이 겹치지 않게** 돌려쓰고, 빨강만 "제일 중요" 고정.

### ④ 상자 속 3층
```html
<div class="bt">라벨</div>                <!-- 2~6글자. §4의 슬롯 이름을 그대로 쓴다 -->
<div class="big">핵심 <b>키워드</b></div>  <!-- 17px 굵게 -->
<div class="eq">부연</div>                 <!-- 13.5px 회색, 생략 가능 -->
```
- `.big`을 여러 개 쌓으면 줄바꿈 나열(왕 한 명 업적 3줄 등).
- 나열은 `<span class="sep">/</span>`, 괄호 보조는 `<small>(호우명 그릇)</small>`.
- **`b`는 시험에 나오는 단어에만.** 다 굵게 하면 아무것도 안 굵은 것과 같다.

### ⑤ 번호 목록 `ul.rel`
순서가 의미 있을 때(유물 3종, 절차)만. 3~5개.
```html
<ul class="rel"><li><span class="n">1</span>비파형동검</li> …</ul>
```

### ⑥ 빈출등급 배지 `.grade` — `.bt` 안에
`<span class="grade gA">A</span>` · gA 금색=3회↑ · gB 초록=1~2회 · gC 갈색=0회
**기출 실측 결과만.** 근거 없으면 배지를 아예 안 단다.

### ⑦ 비교표 `.cmp` — 대비되는 2~3개를 항목별로
```html
<div class="cmpw"><table class="cmp">
  <thead><tr><th></th><th class="c1">대중관광<br><small>자력으로 참여하는</small></th><th class="c2">복지관광<br><small>자력으로 참여 X</small></th></tr></thead>
  <tbody><tr><th>주도자</th><td><b>일반대중</b></td><td><b>정부·지자체·기업</b></td></tr></tbody>
</table></div>
```
비교 항목이 **2줄 이상**일 때 쓴다. 1줄이면 그냥 상자를 나란히 놓는다.

### ⑧ 원문·사료 `.myth` — 항상 그 카드의 마지막 박스
`b`=키워드, `u`=그중 최고 빈출. 아래 `.mean`으로 어려운 말 풀이.

## 4. ★ 순서 규칙 — 이 작업의 핵심

먼저 **어느 유형인지 판정**하고, 그 유형의 슬롯 순서대로 재배열한다.
**있는 슬롯만 쓰고, 없으면 건너뛴다. 순서는 절대 바꾸지 않는다.**

### 유형 A — 나라 (국사: 부여·고구려·옥저·동예·삼한·고조선…)
```
정치 → 경제 → 관직 → 풍속 → 제천행사 → 법 → 지형 · 특이사항
```
- 5개 나라 카드가 전부 이 순서다. 새 나라도 무조건 이 순서.
- `.bt`는 이 슬롯 이름을 **그대로** 쓴다. "정치체제"·"통치" 같은 변형 금지.
- 특산물이 있으면 `경제 — 특산물`, 법 이름이 있으면 `법 — 1책12법`처럼 뒤에 붙인다.
- 유물·건국신화 같은 서술은 맨 뒤 `.myth` 박스로.

### 유형 B — 왕 계보 · 연표 (시간축이 있는 것)
```
시간 오름차순. 그 외 정렬 금지.
```
- `.bt` = `세기/연도 · 이름 [등급배지]` (예: `5세기 = 전성기 · 장수왕 A`)
- 전성기·최중요 왕은 `.box.key`(빨강) + `.bt`에 `= 전성기` 명시.
- 한 왕의 업적이 여럿이면 `.big`을 여러 줄로 쌓는다.
- 나라별로 카드를 나눈다(고구려 1장, 백제 1장, 신라 1장).

### 유형 C — 양식 · 구조 (자원: 주심포·다포·익공, 건축·구조물)
```
이름 풀이 · 위치 → 시대 · 성격 → 세트로 외우는 3종 → 생김새 → 대표 건축물
```
- 대비되는 양식은 **각각 카드 1장**으로 만들고 같은 순서를 유지한다(그래야 나란히 놓고 비교됨).
- 공통 개념(공포 자체 설명 등)은 **별도 카드로 앞에** 둔다.

### 유형 D — 분류 · 목록 (사찰·불상·문화유산 지정종목)
```
상위 분류 = 카드 1장 → 박스 1개 = 항목 1개
```
- 항목 순서는 교재·강의의 공식 순서를 유지한다(삼보사찰 = 통도사·해인사·송광사).
- 개요/정의 카드를 맨 앞에 둔다(예: `관광자원` → `국가지정문화유산` → `1호 세트`).

### 유형 E — 법조문 (법규)
```
조문 번호 오름차순
```
- `.bt` = `5조 <small>제5조(법제상의 조치) 원문 앞부분…</small>`
- 성격이 다르면 카드를 나눈다(`주어암기` / `꼭 암기해야 할 조문` / `특이사항`).

### 유형 F — 개념 · 정의 (관광학개론)
```
정의(누가 정의했나) → 구분 비교표 → 국제 선언 · 헌장(연도 + 원문) → 우리나라 제도 · 연혁
```
- 개론은 사실 나열이 아니라 **"A와 B를 어떻게 가르나"**가 시험이다. 비교표를 카드 가운데에 둔다.
- 정의를 말한 **사람 이름**과 **연도**를 `.tag`·`.bt`에 반드시 남긴다.
- 선언·헌장 원문은 `.myth`로 문장 그대로. 시험에 나오는 구절만 `b`·`u`.

### 카드가 여러 장일 때 — 카드 사이 순서
```
① 개요 · 정의 → ② 본체(위 유형 순서) → ③ 비교 · 세트 → ④ 특이사항
```

## 5. 두서없는 필기 메모를 받았을 때 — 처리 절차

1. **유형 판정** (§4의 A~E 중 하나).
2. 메모를 조각으로 쪼개 각 슬롯에 **배분**한다. 흩어진 같은 항목은 한 슬롯에 합친다.
3. 어느 슬롯에도 안 들어가는 건 마지막 `특이사항` 상자에 모은다.
4. **내용은 하나도 버리지 않는다.** 순서만 바꾸는 작업이다.
5. 강사가 "중요하다 / 시험 나온다 / 별 셋"이라 한 것 → `.box.key`(빨강) 또는 `.tag`에 `★★★`. **메모에 그런 표시가 없으면 아무 강조도 하지 않는다.**
6. **메모에 없는 내용을 채워 넣지 않는다.** 슬롯이 비면 그냥 생략한다. 꼭 필요해 보이면 만든 뒤 "이 부분이 비어있는데 강의에 나왔나요?"라고 따로 묻는다.
7. 메모가 서로 어긋나거나(연도 충돌 등) 알아볼 수 없으면 **추측하지 말고 그 부분만 물어본다.**

## 6. 지켜야 할 것

- **localStorage 금지.** 야간/인쇄 버튼 6줄 외 자바스크립트 추가 금지.
- 색은 직접 쓰지 말고 `var(--w)` 같은 변수를 쓴다(다크모드가 자동으로 따라간다).
- 인쇄 시 카드 1장 = A4 가로 1페이지. **넘치면 카드를 나눈다**(글자를 줄이지 않는다).
- 완성하면 SendUserFile로 보내 확인받는다. **PDF는 따로 요청할 때까지 만들지 않는다.**

## 7. 만들기 전에 물어볼 것 (딱 2개)

1. 어느 단원/주제인지 (메모에 이미 있으면 묻지 않는다)
2. 기출 빈도 배지를 넣을지 (넣으면 기출 파일 실측이 필요해 조금 더 걸림)

그 외에는 묻지 말고 바로 만든다.
